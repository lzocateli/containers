# Política de Segurança

## Escopo
Este repositório mantém imagens de container, workflows e scripts de automação.

## Como reportar vulnerabilidades
Não abra issue pública para vulnerabilidades, segredos expostos ou falhas que possam ser exploradas.

Use contato privado:
- GitHub Security Advisories: aba Security deste repositório (Private vulnerability reporting)
- E-mail: security@zocate.li

Inclua no reporte:
- componente afetado (pasta da imagem, script ou workflow);
- impacto esperado;
- passos de reprodução;
- versão/tag afetada;
- evidências (logs sem segredos).

## Janela de resposta
- Confirmação inicial: até 3 dias úteis.
- Classificação e plano de correção: até 7 dias úteis.
- Correção e divulgação coordenada: conforme criticidade e risco operacional.

## Boas práticas para contribuidores
- Nunca publique credenciais, tokens, segredos, certificados privados ou arquivos `.env`.
- Use placeholders em exemplos e arquivos `*.example`.
- Reporte qualquer exposição acidental imediatamente.

## Escopo fora da política
- Solicitações de suporte geral e dúvidas de uso não são vulnerabilidades.
- Para suporte, use os canais descritos em `README.md`.
