# Código de Conduta

## Nosso compromisso
Queremos um ambiente técnico respeitoso, colaborativo e seguro para todos.

## Comportamentos esperados
- Respeito em discussões técnicas, reviews e issues.
- Feedback objetivo, baseado em fatos e no código.
- Colaboração para resolver problemas de forma construtiva.

## Comportamentos inaceitáveis
- Assédio, discriminação, ataques pessoais ou linguagem abusiva.
- Exposição de informações sensíveis de terceiros.
- Ações maliciosas contra a segurança do projeto.

## Aplicação
Maintainers podem editar, remover ou recusar contribuições que violem este código.

## Como reportar conduta inadequada
Envie relato privado para:
- conduct@zocate.li

Inclua contexto mínimo para investigação (links, data e descrição objetiva).
