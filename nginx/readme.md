### Informe os seguintes parametros para gerar a imagem

Nome da Imagem:
```
lzocateli/nginx
```

Tag version:
```
1.25.0-bullseye
```

Local para o dockerfile:
```
containers/nginx
```

Imagem argumentos: (insira 2 espaços a esquerda para não utilizar)
```
  --build-arg Env_HttpProxy=proxy.xyz.com:80 --build-arg Env_NoProxy=xyz.com
```

Baypass proxy: (insira 2 espaços a esquerda para não utilizar)
```
  xyz\.com
```


### Documentação para uso da imagem

Use o parametro `-it` no lugar `-d` para executar em modo iterativo

```
sudo su -
```

Modo como serviço 

```bash
podman run -d \
    -p 443:443 \
    -v /userapps/ssl:/etc/nginx/ssl \
    -v /userapps/configs/geoip2/data:/usr/share/GeoIP \
    -v /userapps/configs/nginx:/etc/nginx/conf.d \
    -v /var/log/nginx:/var/log/nginx \
    --network=lzo \
    --network-alias=nginx \
    --name nginx \
    lzocateli/nginx:1.25.0-bullseye
    #nuuve.jfrog.io/containers/nginx/linux-x64-1.20.2:9.9.9
```

Modo iterativo

```bash
podman run -it --rm \

```

Se desejar alterar a pagina de erro personalizada, faça nos fontes que estão nesse repositorio na pasta `html`
outra opção é incluir um volume ao iniciar um container, e então criar seu arquivo no volume do host, isso substituira
automaticamente o volume dentro do container.

```
    -v /userapps/configs/html:/usr/share/nginx/html \
```
